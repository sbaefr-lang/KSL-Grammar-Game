📌 형용사 + 명사 수식 규칙
형용사가 명사를 꾸밀 때 형태가 바뀌어요. 형용사를 관형형으로 바꿔야 해요!
조건형태예시
받침 없는 형용사어간 + -ㄴ크다 → 큰 / 싸다 → 싼 / 예쁘다 → 예쁜
받침 있는 형용사어간 + -은작다 → 작은 / 좋다 → 좋은 / 넓다 → 넓은
ㅂ 불규칙ㅂ → 우 + -ㄴ가볍다 → 가벼운 / 어둡다 → 어두운
ㅡ 탈락ㅡ 탈락 + -ㄴ예쁘다 → 예쁜 / 크다 → 큰
✅ 동사는 -는을 붙여요. 형용사는 -(으)ㄴ을 붙여요.
예) 먹는 음식 (동사) vs 맛있는 음식 (형용사)
